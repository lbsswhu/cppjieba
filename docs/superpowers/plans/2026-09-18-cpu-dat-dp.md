# CPU DAT, fused DP and dense HMM implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement independent tasks and review the integrated result.

**Goal:** Implement jieba_cpu_dat_dp_design.md stages 1 and 2 and measure A/B/C/D against identical input.

**Architecture:** Keep Legacy default and its compatibility readers. Add an immutable packed raw DAT built with lowest-fit free-bitmaps, pointer/DAT fused reverse DP with request-local scratch, and independently selectable rolling/dense HMM. Preserve original floating point and output semantics.

**Tech Stack:** C++11, CMake, GoogleTest, Bazel, Python benchmark analysis.

- [x] Baseline: snapshot HEAD, configure Release, run existing CTest. Keep untracked design/archive inputs untouched.
- [x] DAT: CpuCutOptions.hpp, DatModel.hpp, DatBuilder.hpp, src/DatBuilder.cpp. Test bit layouts, raw Unicode, duplicate precedence, finite bit-identical weights, deterministic lowest anchor, budgets and transactional fallback. Logical rows ordered degree/span/id; validate every edge and effective word before publication.
- [x] Integration: DictTrie.hpp frozen write guards (including all loading APIs), startup max length and build diagnostics; Trie.hpp read-only traversal; FusedMPCut.hpp/MPCutScratch.hpp ring scores and uint16 lengths. Retain finite MIN_DOUBLE, strict > and suffix-first addition. Test against original decisions and output.
- [x] Propagate scratch across MPSegment/MixSegment/QuerySegment ranges. Jieba trailing options select a shared dictionary backend. Preserve search, keyword, tags and full segmentation.
- [x] HMM (independent agent): HMMModel.hpp/HMMSegment.hpp/HmmScratch.hpp, rolling 4-state scores and uint8 predecessors, bounded dense emission rows copied from loaded doubles. Independent options and differential tests; maintain ASCII and default predecessor semantics.
- [x] Validation/benchmarks (independent agent): test/cpu_differential.cpp, test/cpu_benchmark.cpp, test/run_cpu_benchmark.py. All public APIs, random ranges, ties, ring wrap, user words, unsupported model, large L and concurrent shared reads. Compare A/B/C/D, short/document/long inputs, single/shared threads, cold load/layout/validation, RSS/peak, allocations/scratch and latency/byte/Rune rates.
- [x] Build: compiled cppjieba target linked by all callers; Bazel srcs, install archive, strict FP compiler flags; verify legacy standalone clients link explicitly.
- [x] Review specification and implementation independently, fix findings, run Release tests and ASan/UBSan, supported compiler smoke.
- [x] Record raw repeated benchmark evidence and docs/cpu-performance.md; document opt-in usage, memory/startup tradeoffs and release recommendation. Keep Legacy default until agreed release gates pass. No automatic release.
